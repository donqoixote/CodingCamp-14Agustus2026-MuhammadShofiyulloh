# Technical Constraints — Expense & Budget Visualizer

## TC-1: Technology Stack
- HTML for structure
- CSS for styling
- Vanilla JavaScript (no frameworks like React, Vue, etc.)
- No backend server required

## TC-2: Data Storage
- Use browser Local Storage API
- All data stored client-side only

## TC-3: Browser Compatibility
- Must work in modern browsers (Chrome, Firefox, Edge, Safari)
- Can be used as standalone web app or browser extension

## Non-Functional Requirements
- NFR-1 Simplicity: clean, minimal interface, easy to understand, no complex setup, no test setup required.
- NFR-2 Performance: fast load time, responsive UI interactions, no noticeable lag when updating data.
- NFR-3 Visual Design: user-friendly aesthetic, clear visual hierarchy, readable typography.

## Folder Rules
- Only 1 CSS file inside `css/`
- Only 1 JavaScript file inside `js/`
- Keep code clean and readable
